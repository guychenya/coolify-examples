Coolify

The open-source, self-hostable platform for deploying applications and managing servers. A cloud-like experience without vendor lock-in.

Core Features

Application Deployment & Server Management

Deploy applications from various sources like Git repositories, Dockerfiles, and Docker Compose files. Coolify provides a comprehensive system for managing your own servers, applications, and databases, offering a cloud-like experience without vendor lock-in.

Database Management

Define schemas, generate data, and manage core data models. Coolify supports various standalone databases like PostgreSQL, Redis, MongoDB, MySQL, and more, with automated backup and restore functionalities.

Docker Infrastructure

Coolify uses specialized Docker images for tooling, real-time communication, and development/production environments. This ensures consistency and efficiency in the deployment pipeline.

HTTP Request Handling & API

A comprehensive API for managing resources, handling incoming HTTP requests, defining API endpoints, and processing webhooks from external services like GitHub and Stripe.

Asynchronous Operations

Leverages a queue system for background processing of tasks like deployments, server management, and scheduled operations, ensuring the UI remains fast and responsive.

Notification System

Get multi-channel, asynchronous alerts for critical application and server events via Email, Discord, Slack, Telegram, and more. You can configure which events you want to be notified about.

Installation

Coolify can be installed with a single command. The installation script automates the setup of a Linux host, including dependency management, system validation, and the deployment of Coolify's components.

wget -q https://get.coollabs.io/coolify/install.sh -O install.sh; sudo bash ./install.sh

Usage Examples

Deploying a Git-based Application

You can deploy an application directly from a GitHub repository. Coolify will handle the cloning, building, and deployment of your application.

# In the Coolify UI, you would:
1. Go to your project.
2. Click on "Create Resource" and select "Application".
3. Choose "Public Git Repository".
4. Enter the URL of your repository (e.g., https://github.com/coollabsio/coolify-examples).
5. Select the branch and build pack.
6. Click "Deploy".

Deploying a Dockerfile-based Application

If your repository contains a Dockerfile, Coolify can build and deploy it as a container.

# In the Coolify UI, when creating an application:
1. Select your Git repository.
2. Choose "Dockerfile" as the build pack.
3. Coolify will detect and use the Dockerfile from your repository.
4. Configure ports and other settings as needed.
5. Click "Deploy".

Managing Environment Variables

You can securely manage environment variables for your applications and services.

# In the Coolify UI, for a specific application:
1. Go to the "Environment Variables" tab.
2. Add your variables as key-value pairs.
3. You can mark variables as "build-time" or "run-time".
4. Secrets are encrypted at rest.
5. Click "Save" and redeploy your application.

Setting up a Database Backup

Coolify can automatically back up your databases to local or S3-compatible storage.

# In the Coolify UI, for a specific database:
1. Go to the "Backups" tab.
2. Configure the backup frequency (e.g., daily, weekly).
3. Choose the storage destination (local or S3).
4. Set the retention policy.
5. Click "Save".

Synchronizing Docker Volumes

You can synchronize Docker volumes between two servers using the `sync_volume.sh` script. This is useful for migrating or replicating data.

# Example of using the script
bash /data/coolify/scripts/sync_volume.sh -s <source_server_ip> -d <destination_server_ip> -v <volume_name>

API

Coolify provides a comprehensive REST API for programmatic interaction. You can manage applications, databases, deployments, and more. API tokens can be generated from your user profile in the Coolify UI.

Example: Get all applications

curl -X GET 'https://<your-coolify-instance>/api/v1/applications' \
-H 'Authorization: Bearer <your-api-token>'

Example: Create an application

{
    "name": "my-new-app",
    "git_repository": "https://github.com/user/repo.git",
    "git_branch": "main",
    "build_pack": "nixpacks",
    "destination_id": "<your-destination-id>",
    "environment_id": "<your-environment-id>"
}

Example: Get server status

curl -X GET 'https://<your-coolify-instance>/api/v1/servers/<server-uuid>' \
-H 'Authorization: Bearer <your-api-token>'
